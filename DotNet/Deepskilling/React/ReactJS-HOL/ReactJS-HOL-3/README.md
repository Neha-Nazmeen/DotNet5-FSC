# ReactJS-HOL-3: scorecalculatorapp — Function Component with Props & CSS

## Project location
`./scorecalculatorapp/`

## How to run

```bash
cd scorecalculatorapp
npm install
npm start
```

The app opens automatically at http://localhost:3000 (or run `npm run build` for a production build).

## Requirements
- Node.js (LTS) and npm installed — https://nodejs.org/en/download/
- Internet connection for the first `npm install` (downloads react-scripts and dependencies)
