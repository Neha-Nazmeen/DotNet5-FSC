# components

Small, reusable presentational building blocks used across multiple pages.

- `header/` — top navigation bar (Hands-On 1)
- `course-card/` — displays a single course; demonstrates @Input/@Output, lifecycle hooks, directives,
  pipes, and ngClass/ngStyle/ngSwitch (Hands-On 2 & 3)
- `notification/` — demonstrates a component-level provider (`providers: [NotificationService]`),
  giving this component its own isolated service instance (Hands-On 6)
