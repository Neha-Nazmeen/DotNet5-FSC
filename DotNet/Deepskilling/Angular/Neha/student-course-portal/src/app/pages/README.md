# pages

Routed page-level components for the portal.

- `home/` — dashboard (Hands-On 1 & 2)
- `course-list/`, `courses-layout/`, `course-detail/` — course browsing, nested routes, route params (Hands-On 3, 7, 9)
- `student-profile/` — enrolled courses, protected by the auth guard (Hands-On 6, 7)
- `enrollment-form/` — template-driven form (Hands-On 4)
- `reactive-enrollment-form/` — reactive form with FormBuilder/FormArray/custom validators (Hands-On 5)
- `not-found/` — wildcard 404 route target (Hands-On 7)
