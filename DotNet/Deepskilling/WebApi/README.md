# WebApi Handson Series

Six progressive .NET Core 3.1 Web API hands-on exercises, each folder building on the previous one.

| Folder | Topic |
|---|---|
| `1. WebApi_Handson` | First Web API — action verbs, HttpRequest/HttpResponse, status codes |
| `2. WebApi_Handson` | Swagger + Postman, Route/Name/ActionName attributes |
| `3. WebApi_Handson` | Custom model class, custom Auth & Exception filters |
| `4. WebApi_Handson` | Full CRUD on the Employee API |
| `5. WebApi_Handson` | CORS + JWT authentication/authorization |
| `6. WebApi_Handson` | Kafka-based chat app (producer/consumer + WinForms client) |

Each folder has its own `README.md` with the specific objectives, what was implemented, and how to run it.

## Requirements
- .NET Core 3.1 SDK (folders 1-5)
- .NET 6 SDK + a local Kafka broker (folder 6)
